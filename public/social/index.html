How this works

    
    
      
  1. Pick. Tap an event on the lab calendar, or start a roundup for the week or the month. Cards that are not events live under Something else.
    2. 
      
  2. Design. Choose a layout, a ground and a size. Fix the words, add a photo, turn on a scan code. Everything stays inside the HeatSync system, so whatever you make matches what the last person made.
    3. 
      
  3. Publish. Save the image, copy the caption written for the platform, copy the alt text, and copy the link. An image cannot hold a link, so the link card is there every time the event has one.
    4. 
    

    
Times always show in lab time, Arizona, wherever you are when you make the card. Nothing you type or upload leaves this page. The only requests it makes are for the public HeatSync Google Calendar: with the site's own key when this page is served from heatsynclabs.org, otherwise with the public key Google's calendar embed uses, and if both refuse, the public feed through a public relay (allorigins.win, codetabs.com or corsproxy.io) because Google does not let other pages read the feed directly.

    
House rules: no emoji, no dashes used as punctuation, no numbers nobody checked, no photos of people who have not said yes. If a class needs a certification, the card says required.
